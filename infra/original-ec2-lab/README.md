# Archived original Terraform EC2 lab (historical)

These three `.tf` files were copied from the supplied project to document the original EC2 instance provisioning work. The lab uses an AMI ID that may no longer be available or valid in the region; this is **reference code, not a tested deployment**. The instance originally created from this project was stopped by its owner and did not serve an application. Do not apply these old files blindly.

For a separate hosting blueprint with an updated dynamic AMI and restricted SSH, see `../aws/`.
